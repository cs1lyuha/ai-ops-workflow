# ai-ops-workflow

Workflow AI pentru operațiuni: o comandă B2B vine pe e-mail, iar sistemul extrage datele, le validează,
verifică stocul și creditul, decide ruta, cere aprobare umană când trebuie, creează comanda,
actualizează CRM-ul și anunță echipa. Fiecare pas e salvat, deci după un crash sistemul continuă de unde a rămas.
